# Poster Plan for CEPAT

## 1) Konsep Umum
- Gaya: modern, clean, public-sector friendly, minim dekorasi.
- Layout: grid 3 kolom dengan card kotak radius 8-12px.
- Fokus visual utama: diagram pipeline di kolom tengah.
- Kesan: cepat, rapi, tepercaya.

---

## 2) Struktur Layout (A1 Portrait)
**Ukuran rekomendasi**: A1 portrait (594 x 841 mm)
**Margin**: 20-25 mm
**Gutter antar kolom**: 10-12 mm

### Header (full-width)
**Kotak besar di atas**
- Judul: CEPAT — Emergency Planning and Action Tool
- Subjudul: Multi-Agent Earthquake Response Support for BPBD
- Nama, institusi, acara (1 baris kecil)
- Logo kecil di kanan

### Kolom 1 (kiri): Problem + Objectives
**Card A: Background / Problem**
- Respon gempa masih manual dan terfragmentasi.
- Data resmi dan berita tidak terkonsolidasi.
- Misinformasi menyulitkan prioritas respons.

**Card B: Objectives**
- Mempercepat analisis awal dan koordinasi.
- Menstandarkan sitrep dan draf pesan.
- Menjaga akuntabilitas lewat human approval.
- Tetap ringan dan bisa berjalan lokal.

### Kolom 2 (tengah): System Pipeline
**Card utama (paling dominan)**
- Diagram pipeline: Monitoring → Intelligence → Analysis → Communication → Coordination
- Ikon tiap tahap: radar, news, report, alert, checklist
- Caption: Data resmi + berita → ringkasan risiko → draf pesan → rencana aksi

**Card kecil: Tech Stack**
- Python, Flask, SQLite, Gemini API, RSS
- Tampilkan sebagai chip/kapsul kecil

### Kolom 3 (kanan): Results + Human-in-the-loop + Impact
**Card A: Results**
- Situation report otomatis.
- Draf pesan multi-format.
- Rencana aksi prioritas (P1, P2, P3).

**Card B: Human-in-the-Loop**
- Draft → Review → Approve/Reject
- Label: Audit log untuk akuntabilitas

**Card C: Societal Impact**
- Respon lebih cepat.
- Informasi lebih tepercaya.
- Koordinasi lintas tim lebih jelas.

**Card D: SDGs Alignment (opsional)**
- SDG 11: Sustainable Cities and Communities.
- SDG 16: Peace, Justice and Strong Institutions.

### Footer (full-width)
**Kotak tipis di bawah**
- QR code demo / repo (opsional)
- Kontak singkat
- Logo institusi kecil

- Diagram pipeline sebagai visual utama.
- Ilustrasi peta/gempa tipis sebagai watermark (opacity 8-12%).

## 6) Draft Isi Ringkas (siap tempel)
**Problem**: Data tersebar, respon lambat, hoaks meningkat.
**Solution**: Multi-agent pipeline + dashboard + human approval.
**Results**: Sitrep, draf alert, rencana aksi prioritas.
**Impact**: Respons cepat, transparan, siap dipakai BPBD.
**SDGs**: SDG 11 (Sustainable Cities and Communities), SDG 16 (Peace, Justice and Strong Institutions).
